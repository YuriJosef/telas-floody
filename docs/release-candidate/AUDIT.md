# Floody 2.0 release-candidate audit

Reviewed November 9, 2026, on `feature/floody-2.0-m3-expressive` for the November 11 school presentation. The review covers the app paths listed below. See [validation](VALIDATION.md) for observed results and [provider requirements](PROVIDERS.md) for the deployment review.

## Data, privacy and platform boundaries

- Geoapify autocomplete starts after three letters or digits and a 600 ms debounce. Selected suggestions supply validated coordinates directly. Typed addresses use forward geocoding, and GPS report coordinates use reverse lookup only when the user asks to capture report location. Failed custom lookups show unavailable state and the Recife shortcuts stay explicit.
- Open-Meteo supplies modeled precipitation accumulation in mm for the interval ending at the displayed validity time. The app formats times in America/Recife. A retained value becomes stale after two model intervals. INMET alerts from RadarMeteorológico have a separate provenance and ten-minute cache. Local reports are a separate, device-local dataset.
- A pending report has no server publication or approval path. The map still only accepts already-approved local records. Reports can include precise coordinates and address text. They are stored in browser storage or AsyncStorage. Avoid entering personal locations or real incident details on shared demo devices. Web browsers without Web Locks serialize within each app runtime only.
- Address search, route endpoints, and optional GPS reverse lookup reach external providers. A visible route is an OSRM road result without flood assessment or turn-by-turn guidance. Expo public configuration is embedded in the client bundle. The repository secret check and key handling are described in [validation](VALIDATION.md).
- Web offers autocomplete and optional GPS following. Native keeps typed forward lookup and a one-shot GPS fix. No new navigation mode, data store, or design system was introduced.

## Readiness and remaining risks

- **Wednesday presentation.** The web candidate can demonstrate the guest entry, Recife dashboard, street map and route planner, pending report history and garage. Use street tiles and sample data. Live services remain best-effort.
- **Native rehearsal.** Both bundles export, but Android and iOS hardware or simulator checks remain open. Rehearse safe areas, keyboard and large text, permissions, map gestures and fallback, persistence, fonts and icons. VoiceOver and TalkBack were not exercised.
- **Public deployment.** Confirm Geoapify key restrictions and shared quota, exact legacy OSRM host terms, native tile HTTP identity/cache, and imagery rights and source credits before broader distribution. Review retention and deletion for precise local reports and an availability strategy for the free endpoints. [Provider review](PROVIDERS.md)
