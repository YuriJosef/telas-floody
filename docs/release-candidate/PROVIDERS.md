# External provider review

Reviewed for Floody's controlled, noncommercial school demonstration. Limits refer to the documented tiers and hosts identified below. A successful HTTP response does not establish permission for public or commercial deployment.

| Provider | Documented terms | Floody status and follow-up |
| --- | --- | --- |
| Geoapify geocoding | API key required. Free tier lists 3,000 credits/day and up to 5 requests/s, shared by keys in one project. Autocomplete, forward and reverse each cost one credit per request. Free-tier use requires a Geoapify follow link and applicable data-source credits. Caching is permitted subject to attribution and terms. [Pricing](https://www.geoapify.com/pricing/) · [Credit costs](https://www.geoapify.com/pricing-details/) · [Geocoding attribution and retention](https://www.geoapify.com/geocoding-api/) | Web and native link Geoapify, OpenStreetMap and OpenAddresses near address entry. The Recife validation returned both underlying datasets. Web retains the most recent successful query for 30 seconds per mounted field. No persistent autocomplete cache, background autocomplete, or automatic retry. If broadening coverage, verify and retain source-specific credits for any other datasets. |
| OSRM demo routing | No key for current demo calls. The OSRM wiki records historical terms for `router.project-osrm.org`, including low usage, identification and OSRM/ODbL attribution. It points to FOSSGIS for its current demo, which publishes one request/s and a map correction link requirement. That numeric limit is documented for the FOSSGIS host. No current numeric or caching rule was verified for Floody's exact legacy host. [OSRM wiki](https://github.com/Project-OSRM/osrm-backend/wiki/Api-usage-policy) · [FOSSGIS usage](https://routing.openstreetmap.de/about.html) | User-initiated routing, source named on the route, and OSM credits on the street map. Exact host terms, native client identity and required links on all layers need review before wider use. Keep demo requests infrequent and avoid bulk calls. The demo host offers no SLA. |
| Open-Meteo | Free endpoint is for noncommercial use, including educational use. Limits below 10,000/day, 5,000/hour, 600/minute and 300,000/month listed on the plan table. No free-tier key. Data is CC BY 4.0. [Terms](https://open-meteo.com/en/terms) · [API and model interval](https://open-meteo.com/en/docs) | Source, units, model status and validity time are displayed. Add a direct source and license link for public distribution. Current client polls once per minute, with no persistent weather cache. Reassess aggregate volume or share requests before opening access to many clients. |
| OpenStreetMap raster tiles | No key or guaranteed SLA. Normal interactive viewing is allowed with visible attribution, identifiable clients/valid browser Referer, HTTPS, and HTTP cache compliance. Honor response headers or retain tiles at least seven days if the cache cannot read headers. Bulk downloads and offline prefetch are prohibited. No published general numeric cap. [OSMF tile policy](https://operations.osmfoundation.org/policies/tiles/) | Default streets use the official tile URL and display OSM credit. Native WebView adds `Floody/1.0`. No offline downloads. Actual native request headers and cache behavior need device verification. Use normal interactive viewing only for the demo. |
| CARTO | Official basemap documentation requires Enterprise licensing for commercial use and a grant for the cited noncommercial offer. No transferable anonymous-CDN quota, key or cache right was established for a custom tile URL. [CARTO basemaps](https://docs.carto.com/faqs/carto-basemaps) | CARTO appears in web attribution for custom street tiles, but it is not a default endpoint. Verify the exact entitlement and cache policy before configuring CARTO. No demo blocker under the checked-in defaults. |
| Esri World Imagery | Esri requires proper credit and reserves the right to classify noncommercial use. World Imagery attribution includes imagery contributors. A public endpoint accepting requests without a key does not establish an unrestricted third-party license. No general numeric quota or offline caching right was established for this legacy endpoint. [Service terms](https://www.esri.com/en-us/legal/terms/web-site-service) · [World Imagery attribution](https://support.esri.com/en-us/knowledge-base/what-is-the-correct-way-to-cite-an-arcgis-online-basema-000012040) | The current satellite layer names Esri but does not show full contributor credits. Use streets in the controlled demonstration. Verify the exact imagery entitlement, source credits and any credential needs before showcasing satellite or distributing it publicly. |
| INMET via RadarMeteorológico | INMET issues the alerts; RadarMeteorológico republishes them. Public feed allows commercial and noncommercial reasonable use without a key and requests linked credit. Alerts are cached ten minutes. No numeric cap or SLA is stated. [Feed conditions](https://radarmeteorologico.com.br/api-publica) · [Official INMET source](https://avisos.inmet.gov.br/) | The app links both sources, shares collection requests, respects the ten-minute cadence and identifies cached data during outages. No location coordinates are sent to the alert endpoint. Suitable as a supplementary feed in the demo. |
| Parallelum FIPE v1 | The operator documents 500 unauthenticated calls per 24 hours, or 1,000 with a free token. No specific cache/redistribution permission was found on the v1 reference. [Operator's v1 documentation](https://deividfortuna.github.io/fipe/) | Uses unauthenticated make/model queries and labels the catalog FIPE. User-entered garage data remains local; it is not a mirror of the API. Avoid bulk calls and confirm attribution, cache and reuse conditions before expanding public use. |

Geoapify browser keys are visible in the Expo bundle and request inspector. Keep the real value in ignored `Floody/.env.local`, use separate restricted demo keys as appropriate, monitor usage, and rotate after exposure. A CORS response setting is not an authorization restriction. Native has no reliable browser referrer; apply an IP rule if feasible and validate the actual device flow. A production proxy, provider contract, or stronger access controls are separate decisions. [Geoapify key restrictions](https://myprojects.geoapify.com/help/api-keys/)

Address text goes to Geoapify during web typing after 600 ms and three letters or digits, or when a lookup is submitted. GPS coordinates are sent to reverse geocoding only after a user requests the report location. Do not use private home addresses or real incident details in shared demonstration captures.
